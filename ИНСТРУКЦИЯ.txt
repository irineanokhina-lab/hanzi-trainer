字研 — приложение для Android и Mac

СОСТАВ
index.html — тренажёр китайского со всеми упражнениями, интервальным повторением и резервными копиями
manifest.webmanifest + service-worker.js + icons/ — установка на главный экран и работа без интернета

НА МАКЕ — ИСПОЛЬЗОВАТЬ СРАЗУ
Откройте index.html двойным щелчком. Программа работает локально без интернета.
Чтобы установить её как отдельное приложение, откройте опубликованную HTTPS-версию в Chrome или Safari.

НА ANDROID — УСТАНОВИТЬ КАК ПРИЛОЖЕНИЕ
1. Разместите ВСЕ файлы из этого архива на HTTPS-сайте, не меняя их имён и расположения.
   Бесплатный вариант — GitHub Pages: создайте публичный репозиторий, загрузите файлы
   (index.html, service-worker.js, manifest.webmanifest, папку icons) в корень,
   включите Settings > Pages > Deploy from a branch > main > /(root).
2. Откройте полученную ссылку в Chrome на Android.
3. Нажмите меню ⋮ > «Добавить на главный экран» > «Установить» (формулировки могут отличаться).
4. Запустите приложение с главного экрана. После первой успешной загрузки с сайта оно может
   работать и без интернета.

НА MAC — УСТАНОВИТЬ КАК ПРИЛОЖЕНИЕ
Откройте опубликованный сайт в Chrome и воспользуйтесь командой «Установить»/«Создать ярлык»
(формулировка зависит от версии браузера). В Safari на актуальной macOS: Файл > Добавить в Dock.

ВАЖНО О ДАННЫХ
Подборки и прогресс хранятся отдельно на каждом устройстве в хранилище приложения.
Автоматической синхронизации пока нет. На первом устройстве нажмите «Сохранить резервную копию»;
на втором — «Восстановить из копии». Восстановление ЗАМЕНЯЕТ все текущие данные второго устройства.
Резервные копии лучше делать периодически. Если запускать Mac-версию сначала как файл, а
потом как сайт, данные тоже будут раздельными: для переноса используйте резервную копию.

ОГРАНИЧЕНИЯ
Приложение не является APK. Установка PWA с иконкой на Android требует HTTPS или localhost;
локальный index.html нельзя установить как полноценное офлайн-PWA через обычный file://.
После очистки данных браузера прогресс может исчезнуть; сохраняйте резервные копии.

НОВИНКИ
— Яркая зелёная/красная подсветка ответов и сборки слов.
— Вкладка «Словарь HSK 1–2»: поиск, выбор нескольких слов и создание подборок.
— Два списка: HSK 2025/26 и HSK 2.0; они различаются по составу.
— Произношение 🔊 через китайский голос, установленный на Android/Mac (это синтез речи, не записи дикторов).
— Данные словаря Zitou, CC BY 4.0; традиционные формы/уровни — complete-hsk-vocabulary, MIT.
Словарь с полным набором загружается из открытой базы при первом подключении к интернету и
затем сохраняется в браузере для офлайн-работы. Без сети сразу работает небольшой встроенный список.
Если автоматическая загрузка заблокирована, можно скачать hsk_uz_ru.csv по адресу
https://huggingface.co/datasets/Maqsudjonpolatov/hsk-chinese-uzbek-russian/resolve/main/hsk_uz_ru.csv
и импортировать его через кнопку в словаре.
Резервная копия сохраняет пользовательские подборки и прогресс, а не весь общий словарь.

О ПРОИЗНОШЕНИИ
В настройках Android или macOS должен быть установлен голос китайского языка (Mandarin).
При отсутствии такого голоса приложение покажет подсказку; произвольный русский голос
для китайских слов не используется. Синтезированные звуки могут отличаться от произношения учителя.

ЧЕРЕЗ TELEGRAM
Лучший способ — отправить себе в «Избранное» ссылку на опубликованную HTTPS-версию
тренажёра. Откройте ссылку на Android в Chrome (если запустился встроенный браузер
Telegram, выберите меню > «Открыть в браузере»), затем меню Chrome > «Добавить на главный экран».
Для просто передачи файлов можно переслать весь ZIP-архив через «Избранное», скачать и
распаковать на телефоне, но такой HTML-файл сам по себе не устанавливается как PWA.
